# И-Цзин · Книга перемен — мобильное веб-приложение (PWA)

Гадание по Книге перемен: бросок трёх монет, гексаграмма и толкование под вопрос.
Ставится на iPhone через «На экран Домой», работает офлайн. Без сервера и без базы данных.

**Живая версия:** https://odysdasw.xyz/iching/

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | Экраны: главная, вопрос, бросок, результат, история, «как мы читаем» |
| `app.css` | Мобильная вёрстка: safe-area iPhone, тёмная тема, анимации |
| `app.js` | Интерфейс, тренер вопроса, история в localStorage |
| `engine.js` | Бросок, гексаграммы, правила Чжу Си, сборка ответа. Без DOM — тестируется в Node |
| `data.js` | **Корпус:** 64 гексаграммы, триграммы, таблица Вэнь-вана, категории |
| `sw.js` | Офлайн-кэш (service worker) |
| `manifest.webmanifest` | Установка на телефон |
| `icons/` | Иконки 192/512/maskable/apple-touch |
| `test.js` | Тесты движка |
| `autodeploy.sh` | Скрипт автодеплоя (лежит на сервере как `/usr/local/bin/iching-autodeploy`) |

## Локальный запуск

```bash
python3 -m http.server 8000    # http://localhost:8000
node test.js                   # тесты движка
```

## Деплой

**Автоматически.** Push в `main` → в течение 2 минут таймер
`iching-autodeploy.timer` на сервере подтягивает изменения, прогоняет `node test.js`
и только при успехе раскладывает файлы в `/var/www/iching`.
Если тесты упали — деплой отменяется, коммит помечается как упавший и повторно не пробуется.

Лог: `journalctl -u iching-autodeploy.service` и `/var/log/iching-autodeploy.log`.

**Вручную:** `HOST=<адрес> ./deploy.sh`

**Важно:** после правок `data.js` / `app.js` / `app.css` поднимайте версию кэша
в `sw.js` (`iching-v1` → `iching-v2`), иначе у пользователей останется старая версия.

## Установка на iPhone

Safari → открыть сайт → «Поделиться» → «На экран Домой».

## Контент

Тексты в `data.js` — черновые авторские трактовки, **не перевод** классических
комментариев. Требуют редакторской сверки.

Тексты 384 линий пока отсутствуют: вместо них общий смысл позиции
(`engine.js` → `POSITION`). Это ключевая часть контента — в 65% бросков ответ
строится именно по линиям. Чтобы добавить, допишите гексаграмме поле:

```js
lines: { 1: "текст первой линии", /* ... */ 6: "текст шестой линии" }
```

Код менять не нужно.
